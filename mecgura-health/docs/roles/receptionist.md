# Receptionist — quick guide

Front desk: registration, appointments, queue and billing desk.

## What you do here
1. **Patients**: search (name, ID, mobile), register, edit contact details.
2. **Appointments**: book, reschedule, cancel; confirm online requests.
3. **OPD queue**: check in arrivals, token numbers, priority/emergency flag.
4. **Billing**: create invoices, collect payments (cash/UPI/card record), request refunds (approval needed), apply discounts within policy.
5. **Follow-ups**: call lists and outcomes.

## Good to know
- Verify identity before changing contact details.
- Refunds are requests; an Accountant or Admin approves/processes them.
- Receipts and invoice numbers are generated automatically — never write them by hand.

Need help? Ask your Clinic Admin; they can contact MECGURA support with the request id shown on any error.
