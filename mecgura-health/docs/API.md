# HTTP API reference

_Generated by `npm run docs:api` from the route files (339 endpoints). Do not edit by hand._

## Conventions
- Responses: `{ "ok": true, "data": … }` or `{ "ok": false, "error": { "code", "message", "requestId" } }`. Send `X-Request-Id` back when contacting support.
- Browser/session routes are same-origin only (CSRF check on every write). They are not a public integration API.
- Tenant is always taken from the session or the host — never from a request field.
- Rate limits: per-user (reads 1200/min, writes 240/min), plus sign-in and public-form throttles. HTTP 429 carries `Retry-After`.
- Machine integrations use **API keys** (`/api/v1/*`, header `Authorization: Bearer <key>`): scoped, hashed at rest, expiring, optional IP allow-list.
- The "Permission" column shows a permission declared on the route; where it says *enforced in the service layer* the service checks the permission, the clinic and the record's ownership before touching data.
