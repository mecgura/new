# MECGURA logo

Place the official MECGURA logo here (do not redesign it):

- `mecgura-logo.svg` (preferred) or `mecgura-logo.png` — full logo used in the navbar, sidebar and footer.

The app loads `/brand/mecgura-logo.svg`, then `/brand/mecgura-logo.png`. If neither file exists it shows the
plain text "MECGURA" as a temporary fallback.
