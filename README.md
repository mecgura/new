# Aurora

Vite + React 19 + TypeScript + Tailwind v4 + framer-motion landing hero.

## Setup

```bash
npm install
curl -L https://pub-1e5b4001b36b47e28e6a2fb775966a79.r2.dev/templates/aurora/hero.mp4 -o public/hero.mp4
npm run dev
```

`public/hero.mp4` is the hero background video (not committed yet — download it with the command above).
